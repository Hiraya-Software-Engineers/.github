**E-SIGN MO** is a web-based learning platform designed to help users learn and practice **Filipino Sign Language (FSL)** through interactive lessons, real-time sign detection, instant feedback, and gamification.

The system combines **computer vision, machine learning, and gamified learning** to provide an engaging environment for practicing Filipino Sign Language.

---

## General Objective

To develop **E-SIGN MO: Gamified Filipino Sign Language Learning System**, a web-based learning platform where users can learn and practice Filipino Sign Language through real-time sign detection, structured lessons, instant feedback, and gamified features such as badges, streaks, and leaderboards.

---

## System Features

### FSL Gesture Detection

Uses a webcam or digital camera to capture the user's hand and detect selected Filipino Sign Language gestures.

### Structured Lesson Modules

Provides progressive lessons covering:

* FSL Alphabet
* Numbers
* Commonly Used Signs
* Everyday Expressions

### Instant Feedback & Confidence Scoring

Provides immediate recognition results and confidence scores while users perform signs.

### Gamification System

Encourages continuous learning through:

* Leaderboards
* Achievement Badges
* Day Streaks
* Points and Rewards

### Speed Challenges

Timed exercises designed to improve sign recall, recognition speed, and practice consistency.

### User Progress & Admin Analytics

Learners can monitor their individual progress while administrators can view:

* User activity
* Learning progress
* Challenge completion
* Engagement metrics
* Overall platform performance

# Project Objectives

The project aims to:

1. Capture and detect selected FSL hand gestures using a webcam or digital camera.
2. Design structured and progressive lesson modules covering the FSL alphabet, numbers, and commonly used signs.
3. Provide users with instant feedback and confidence scores during sign practice.
4. Implement gamification features such as leaderboards, badges, and streak tracking.
5. Develop an administrative dashboard for monitoring user progress, challenge completion, and platform engagement.
6. Evaluate the usability and effectiveness of the system in supporting FSL learning and skill acquisition.
